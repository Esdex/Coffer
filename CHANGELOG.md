# Changelog

## [Unreleased]

### Added
- Edit in another app, in a file's menu: an editor such as WPS or OnlyOffice changes a decrypted copy, and each save goes back into the vault in place of the file, where it is now. A save made while Coffer is locked goes in at the next unlock; one that finds the file deleted comes in beside it as "name (edited)". The copy stays decrypted on the phone while you edit and for an hour after the last save. It can be turned off in Settings, Security.
- The video seek bar shows how far the video is loaded, in grey under the part played.
- Adding or moving something into a folder that already has its name asks what to do: for a file Replace, Keep both or Skip, for a folder Merge, Keep both or Skip, with a tick to do the same for the rest. Keep both numbers the new one, as in report (1).pdf. Replace deletes the old file only once the new one is uploaded whole, so a failed upload leaves it. Names that differ only in case count as the same. Settings, Storage: When a name is taken, Ask (the default), Keep both, Skip or Replace.
- A new folder or a rename cannot take a name already used in the same folder.

### Changed
- Creating, renaming and moving folders and files go to Telegram through the transfer queue, which keeps them when Coffer is closed and shows them in Transfers: what they do, how many have gone, and Telegram's pause with a countdown when it asks for one. The list changes once Telegram has each one. A folder brought in from the phone queues its folders and all its files at once; before, a folder of many folders stopped for minutes with nothing on screen when Telegram asked for a pause, and lost its files if Coffer was closed meanwhile.
- Deleting goes through the same queue: a folder with everything in it is a few messages, its rows say Deleting until Telegram has them, and a delete cut short by closing Coffer goes on when it opens. Before, each file and folder was a message of its own, so a large folder took most of an hour of Telegram's pauses, and closing Coffer meanwhile left it half deleted.
- Several of these changes go in one message to Telegram, up to some 35 with ordinary names, so a folder of many folders is a few messages rather than one a folder, and Telegram's pause rarely comes. This is a new version of the vault format: Coffer 1.0.0 does not see folders created, renamed or moved with this version, so update every device that opens the vault.
- The path under the top bar shows at the root too, with the house marked as the place on screen, so going into a folder and back no longer moves the list.

### Fixed
- In the normal theme the path under the top bar has the bar's background; the list no longer shows through it.

## [1.0.0] - 2026-11-15

### Added
- The app icon: a golden chest on navy, shaped for every launcher's mask, with a themed version for Android 13 and later that follows the wallpaper's colours.
- Sign in to Telegram with a QR code or a phone number, including two-step verification and email codes; the code from Telegram goes into a row of cells. The phone number is one field in two halves, the country code and the number: the country's flag shows by the code, the number takes the country's own spacing with the digits still to come as a hint, the cursor moves on once the code is whole and back when the number is erased, and a whole number pasted in splits by itself. Over it, an account picture with a key on its corner that turns now and then.
- Built-in Telegram API keys, so signing in needs nothing from my.telegram.org; your own keys (api_id and api_hash) remain an option on the sign-in screen.
- A welcome of four pages, each with a picture of its own: what Coffer is, with its icon and light running over it; encrypted on this phone, file names turning into noise; only you hold the key, a key turning; kept in your own Saved Messages, a message with a bookmark dropping in.
- Create a vault: a password checked for strength, with a padlock over it that shuts step by step as the password gets stronger and clicks shut once it will do; a 24-word recovery key, and a check that it was written down. Wherever the recovery key shows or is typed in, it is kept off screenshots, screen recordings and the recent apps screen.
- The vault password is stretched with Argon2id at 128 MiB and 4 passes, about half a second on a recent phone; an existing vault takes the new strength at its next password change.
- After the vault first opens, two pages laid out as the welcome say what to leave alone in Saved Messages: Coffer's notes starting with coffer:, which hold the vault itself, and the cfr_ documents, the files' parts. Deleting and moving files is for Coffer.
- Unlock the vault with its password, the recovery key, or a fingerprint or face. The phone's PIN does not open it, and adding a new fingerprint turns fingerprint unlock off until the next password unlock.
- The vault locks after 5 minutes in the background.
- Add files to the vault: they are encrypted on the phone and sent to Saved Messages; interrupted uploads resume. All uploads, downloads and caching run as one queue with one notification: how many, how many done and how far, instead of one notification per file. The Transfers screen shows each file as the files list does, with its preview and which way it goes; failures first, then what is moving, then what waits, and what it waits for: the network, Telegram's request to wait, or a retry, with a countdown. Over the list, how far the whole queue is; Cancel all in the menu, after a confirmation.
- Files list with search by name and sorting by name, date or size; files added from other devices show up too.
- The title of the files list says when Telegram cannot be reached: Waiting for network, Connecting, Updating, in grey with light running across it.
- Select several files and folders with a long press to move, save or delete them together; saving puts decrypted copies into a folder you pick.
- Add a whole folder from the phone, and save a vault folder back to the phone, keeping its subfolders.
- A delete can be undone for a few seconds before it goes to Telegram, where it is final.
- Pictures and videos open in Coffer's own viewer, read from Saved Messages a piece at a time and never written out decrypted: swipe through a folder, pinch or double tap to zoom a picture; HEIF, animated GIF and WebP included. A video starts before it is downloaded, seeks anywhere, and has double tap to skip 10 seconds, swipes for volume and brightness, hold for 2x, speed, repeat, a touch lock and full screen; each extra has a switch in Settings, Player.
- PDFs open in Coffer too, up to 256 MB, decrypted into memory with progress shown while they load: pages drawn as they scroll into view, pinch or double tap to zoom with the text kept sharp, and a page counter. A password-protected PDF says so and can still be opened in another app.
- Text files open in Coffer too: notes, logs, config files, JSON, XML, code and subtitles up to 256 KB (larger ones open in another app), with line numbers and syntax colours; Markdown opens formatted, with headings, lists, checkboxes, tables and code blocks, and one tap shows its source. Font size, monospace, line wrap, line numbers, visible spaces, colours and formatted Markdown each have a setting in Settings, Text viewer.
- Music and other audio play in Coffer, read in place like video: the tracks of a folder one after another, with the cover, title, artist and album from the tags, a seek bar, previous and next, shuffle and repeat. A call or another app's sound pauses it, and so do headphones coming out. It plays on in the background, with its controls in a notification, on the lock screen and on headset buttons, and when the vault locks the track playing finishes, with nothing after it played from a locked phone. Back folds the player into a card floating over the files while music plays, with the song's progress along its top, and closes it when paused; the notification says only Coffer unless you choose to show the track. Both have a switch in Settings, Player. The progress bar is the song's waveform, worked out from the whole song as soon as it plays, whatever the player is doing; the first time the song is downloaded whole for it, after that the waveform shows at once. It has its own switch in Settings, Player.
- Open a file in another app, or save a decrypted copy anywhere; the copy is checked against its checksum.
- Delete a file from all devices.
- Folders: create, rename, move and delete them (a folder is deleted with everything in it, after a confirmation); rename and move files; new files go into the folder on screen. Changes made on one device show up on the others.
- Index snapshots in Saved Messages: a new device, or one long offline, loads the latest snapshot instead of reading the whole history. The last 3 are kept.
- Settings, Storage: what the vault holds by kind (pictures, videos, music, documents, other) on a ring, each kind opening its files largest first, with a tap taking you to the file's folder; and what Coffer keeps in Saved Messages: parts of files, changes, index snapshots, the vault header, and how many messages are your own.
- Settings, On this phone: what Coffer takes up on the phone apart from the vault: the file cache, Telegram's database, Coffer's index and temporary files.
- A file cache: files opened, played or saved keep their encrypted pieces on the phone, so they open again without a download and without traffic. Up to 2 GB by default (500 MB to 10 GB), the files read longest ago making room first, never one that is open. It can be turned off, cleared, or cleared each time the vault locks, in Settings, On this phone.
- Cache on this phone: a file, a folder with its subfolders, or a selection brought onto the phone whole, so it opens at once and with no network. Before it starts Coffer says how much it is and offers a larger cache when it would not fit; it shows in Transfers with its progress, can be cancelled, goes on after the vault locks, and picks up where it stopped. A file whole on the phone has a green check on its icon.
- Previews on the file icons: photos, a frame of each video and the cover of each song, with the file's type still marked on the corner. Each is made once, as the file comes into view, from as little of it as will do (a photo's own small copy, the start of a video, the tags of a song), and kept on the phone encrypted with its key; they go with the file, on sign-out, or when turned off in Settings, On this phone, where their size is shown.
- File sizes hidden from Telegram: new uploads are padded inside the encryption (PADMÉ), so a file cannot be recognised by its exact size, at about 1 to 2 percent more traffic; on by default, with a switch in Settings, Security. Captions and changes are padded to one length per kind, so they no longer show how long a file name is, and index snapshots are padded too. Encrypting each upload with a fresh key already made every copy of a file look different. Older files and messages are read as before.
- Rescan Saved Messages from the menu, to rebuild the list of files and folders from scratch.
- Integrity check, weekly and from the menu: finds files with missing parts, brings back files the list missed, removes leftovers of unfinished uploads and deletions, and clears out old operations that are no longer needed.
- Settings: auto-lock after 1 to 60 minutes or off, unlock with fingerprint on or off, block screenshots, weekly integrity check on or off. Integrity check, rescan and log out moved here; log out asks first.
- Decrypted copies opened in another app are removed from the phone about 10 minutes after opening, and at the latest when the vault locks or Coffer next starts.
- Change the vault password, and show the recovery key again; both ask for the current password first (a password change takes the recovery key instead). A password change locks the vault on your other devices, and only the new password opens it there.
- Delete the vault, in Settings, Vault: after the current password and the word DELETE typed out, every file of the vault and everything Coffer keeps for it goes from Saved Messages, for good and on every device, with its progress shown; your own messages and anything Coffer cannot open stay. Cut short, it can be run again. Afterwards Coffer stays signed in and offers a new vault, and other devices say the vault was deleted there.
- Log out from the screen that creates a vault, to sign in with another account instead.
- Restore a vault with its recovery key: if Coffer's pinned note that holds the vault was deleted in Telegram while the files are still there, the 24 words and a new password bring it back, files and all. It is offered on the screen for a new vault, and on the unlock screen when the recovery key belongs to none of the vaults found.
- A forgotten password: open the vault with the recovery key, then set a new password in Settings, Vault, Change password, with the 24 words in place of the current password.
- Settings, About links to the source code on GitHub, to the documentation and the privacy policy on the website, and to Report a problem, which opens a bug report on GitHub with Coffer's version, Android's and the phone's model filled in.
- Support the project, first in Settings: GitHub Sponsors, Ko-fi and crypto wallet addresses that copy with a tap, under a gold star that fires confetti. In the GitHub and F-Droid builds only; the Google Play build has no such page.
- Share to Coffer from any app: one file or several, into a folder you pick; Coffer returns to the app you shared from.
- A new look, shared with Arcanum: grouped settings, large collapsing titles, file type icons, a path bar, search in the top bar, one + button for files and folders, sliding transitions, animated progress and results, and a paged welcome.
- Appearance settings: theme (system, light or dark), pure black for AMOLED screens, and wallpaper colours.
- Every screen polished to one standard: one scale of motion and corners, smooth transitions between steps and screens, errors under the field they are about, a spinner inside the button that is working, an eye in every password field, digits that keep their width as they count, and previews wherever a file is shown. The mini player, the actions on a selection and short notices float as cards over the bottom of the screen, frosted glass in pure black like the top bar; menus are rounded and, in pure black, black with a fine edge. Every delete asks with a red button. One set of colours for kinds of file, the same on their icons and on the Storage ring. Empty places (a new vault, an empty folder, a search with no match, no transfers) have a little ghost wandering to and fro, and a file that cannot be shown gets a cross drawn in a circle once. Every animation is drawn by Coffer itself in the theme's colours, with no animation files: a check or a cross when an operation ends, dots rising in turn while something loads, and on the sign-in steps a key for the API keys, a message filling with dots for the code, and a shutting padlock for the Telegram password. Locking the vault from the menu sends a padlock flying from the Lock item to the unlock screen, shutting on the way; the unlock screen shows a padlock instead of a safe.
